The password system for NEXA-web is now complete and live at https://carolinehvermette.github.io/NEXA-Web/. I have copied Ahmed, since it follows the same model he introduced for URDM.

- Visitors request access from the NEXA-web section of the RHlab Tools page, and each request arrives in the lab Gmail with their email, role and intended use.
- Approved users are added to a Google Sheet, then receive an invitation email with the link and their login. Every page of the site asks for this login and shows the intended-use disclaimer.
- A login lasts 7 days, after which the site asks for it again. Each account is tied to one browser, as with URDM.

I tested the full process with a real request and sign-in, and it works as expected.

I have also updated the Handover and Maintenance Guide (attached). The new section 14.7 explains how to approve a request, add a person to the sheet, send the invitation, reset a user's browser and withdraw access.
