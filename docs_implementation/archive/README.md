# Archive, build notes from earlier rounds

These 28 files are the plans, task lists and walkthroughs written while the
earlier rounds of the tool were built: the Layer 1 envelope refactor, the PV
page layout, the colour palette, the database updates, the NECB zone work.
The work they describe is finished and shipped.

They are kept here rather than removed. The 2026-08-24 reorganisation moved
them out of `docs_implementation/` and git read that as a deletion; restoring
them under `archive/` says plainly what they are and preserves them in the
repository, which is where they have always been.

They are a record, not a specification. Where one of them disagrees with the
site, the site is right.
