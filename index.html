Welcome to the Layered Modular Neighbourhood (LMN) Tool

An early stage decision support tool for comparing neighbourhood designs at pre-feasibility.

What do you have in mind?

What this tool is for

It compares neighbourhood units that have already been simulated, so that an energy result can be read early, before a design exists. It is a pre-feasibility comparison tool. It does not design a neighbourhood, it does not optimise one, and it is not a substitute for detailed building energy modelling later in the project.
